ABOUT HAYLEN

Built with C++.
Scripted with Lua.

Haylen is an open-source engine for 2D games and apps. It brings graphics, physics, UI, audio and native plugins into one engine.

HOW IT WORKS

A native engine.
A shared app project.

The engine is written in C++. Its API is also available in Lua through Varn, so you can write your app in Lua, work directly in C++, or add native plugins.

A Lua project contains an app.json file, a source/ folder for code and a content/ folder for assets. The same project can run on each supported platform.

Haylen supports 2D today. The engine is organized so 3D can be added later.

THE PLUGIN SYSTEM

Use native code
from your Lua app.

A plugin packages its code, assets and platform implementations together. Your Lua app calls its API without having to manage each platform separately.

DEVELOPMENT

Create it. Run it.
Make a change.

Use the Haylen command line to create and run a project. Hot reload updates your running app as you edit its Lua code and assets.

Build a web version when you want to test it in a browser.

Follow the setup guide {{ICON_ARROW_RIGHT}}
Terminal{{ICON_TERMINAL}} 
# Create a project
haylen new ~/apps/my-app \
  --name "My App" \
  --identifier com.example.myapp

# Run the app
haylen run ~/apps/my-app

# Build and run for the web
haylen run ~/apps/my-app --platform web
