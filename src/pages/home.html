PLUGINS

Add native features.
Keep your Lua code.

Need a platform API or a native library? Add a plugin and give your app a Lua API to use it.

Haylen supports plugins written in Swift, Objective-C, Kotlin, Java, JavaScript and C++. Each platform can have its own implementation behind the same Lua API.
