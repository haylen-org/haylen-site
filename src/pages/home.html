01 / ENGINE SYSTEMS

Graphics, physics
and app interfaces.

Draw a world, give it physics, build an interface and connect your controls. Work with the same engine from the first screen to the finished project.

{{ICON_LAYERS}} GRAPHICS01

Graphics & animation

Draw sprites and tile maps. Animate characters with frames, skeletons and timelines. Shape the final look with lighting, shaders and particles.

  • Sprites & animation
  • Lights & shadows
  • Custom shaders
{{ICON_INTERFACE}} INTERFACES02

App interfaces & layout

Create screens with buttons, forms, text and lists. Add navigation, themes and layouts that fit different screen sizes, with screen reader support.

  • UI components
  • Flexible layouts
  • Accessibility
{{ICON_PHYSICS}} PHYSICS03

Physics & navigation

Work with rigid bodies, collisions, joints and vehicles. Add tile maps, pathfinding and game AI to help characters find their way.

  • Bodies & joints
  • Collision detection
  • Navigation

local graphics = require('haylen.graphics2d')
local scene = require('haylen.scene')

-- Start a scene and draw in screen coordinates.
scene.push({
    render = function()
        graphics.beginScreen()
        graphics.drawText(nil, 'Hello, Haylen.', 48, 48, {
            size = 32,
            color = '#FFFFFFFF',
        })
    end,
})
