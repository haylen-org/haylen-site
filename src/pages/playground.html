HAYLEN PLAYGROUND

Using the playground

Choose an example, edit its files, and press Play to try your changes.

  1. Open and edit files. Choose a file to edit it. Use the left toolbar to show or hide panels. Closing a file does not delete it.
  2. Try your project. Play starts it, Pause holds it in place, and Stop ends it. Click or tap the preview to use it. The console shows messages and errors. Click an error's file name to open that line.
  3. Try different screen sizes. Use the phone, tablet and desktop buttons. Rotate turns the preview sideways; Fit fills the space. Hide the console for more room.
  4. See edits as you work. Auto update applies edits while your project runs. If a change does not appear, press Play again. If your code freezes the tab, reload it to reopen your last saved files.
  5. Add or replace files. Drop files into the file list or use Import. A Haylen project ZIP replaces all current files after you confirm.
  6. Keep a copy. Your edits save in this browser. Export ZIP downloads a backup. Clearing your browser data removes your saved project too.
  7. Work without internet. Wait for “Available offline” before disconnecting. Playground updates keep your saved files. To get an example's latest code, load it again from Examples.

This playground runs Haylen projects written in Lua. To run C++ code or add your own plugins, use Haylen on your computer.
