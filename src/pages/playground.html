HAYLEN PLAYGROUND

Your local workspace.

  1. Manage files. Open the explorer from the left toolbar. Create, rename, move or delete files and folders. Drop files into the explorer to import them locally.
  2. Edit your project. Select a file to open it. Use the tab's close button to close it without deleting it. Hide the editor or explorer from the left toolbar to make more room.
  3. Run and inspect. Play starts the current project. Pause keeps its state. Stop ends the preview. Click or tap the preview to use its controls. The console shows output and errors. Click an error with a file location to open that line.
  4. Check screen sizes. Use the smartphone, tablet and desktop buttons above the preview. Each sets the app viewport to that size and scales it to fit. Rotate swaps its width and height. Fit uses the available panel space. Hiding the console gives the preview more room.
  5. Apply changes. Hot reload applies supported Lua and asset edits while running. Initialization changes may restart the project. Correct a Lua error and use Play for a clean run.
  6. Import a complete project. A project ZIP replaces the whole workspace after confirmation. Include the project settings and main Lua script, keeping the project's folder structure. Importing removes all previous files from the workspace.
  7. Choose an example. Open Examples to load a game or app project. Export your current work first if you want to keep it. Examples are available offline after the offline indicator is ready.
  8. Keep your work. Changes save in this browser. Export ZIP creates a portable backup. After the offline indicator is ready, you can keep working without a connection.

C++ and native plugin compilation use the Haylen build tools. This browser runtime cannot interrupt an infinite loop yet.
